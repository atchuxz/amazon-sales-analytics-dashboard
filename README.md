# Amazon Sales Analytics Dashboard

## 📌 Project Overview

This is an end-to-end Data Analytics project developed using Excel, SQL, and Power BI. The project focuses on analyzing Amazon ecommerce sales data to identify sales trends, customer purchasing behavior, regional performance, fulfillment efficiency, and key business insights.


## 🚀 Project Features

* Data Cleaning & Preprocessing using Excel
* KPI Analysis & Business Metrics
* Pivot Table Analysis
* SQL Queries for Business Insights
* Interactive Power BI Dashboard
* Advanced Dashboard UI Design
* Business Insights Report

## 📊 KPIs Included

* Total Sales
* Total Orders
* Quantity Sold
* Average Order Value
* Cancellation Rate
* Delivery Success Rate
* B2B vs B2C Orders
* Fulfillment Analysis

## 📈 Dashboard Visualizations

* Monthly Sales Trend
* Sales by Category
* Sales by State
* Order Status Analysis
* Fulfillment Analysis
* Interactive Slicers & Filters

## 🛠️ Tools & Technologies Used

* Microsoft Excel
* SQL (MySQL)
* Power BI

## 📌 Business Insights

* Maharashtra generated the highest sales revenue.
* The “Set” category contributed the highest sales.
* April recorded peak sales performance.
* Amazon fulfillment handled most successful deliveries.
* Cancellation rate analysis identified operational improvement areas.
